## ADDED Requirements

### Requirement: Final R7 typed parity evidence SHALL be versioned
The sidecar contract inventory SHALL include an immutable corpus, development-only Rust driver, Node checker, stable report identity, and complete scenario-aware observation comparison for Knowledge Checkpoint, Durable Bundle, WebDAV Sync, and Debug/Maintenance.

#### Scenario: Candidate evidence is audited
- **WHEN** the corpus, driver, checker, workflow, or report contract changes
- **THEN** Core contract tests and every candidate target evaluate the same versioned evidence before smoke
- **AND** the checker uses physically isolated repository, canonical, WebDAV state, and remote roots
