## Context

工作台将已保存的构建目标投影为 pendingScope，成功发布后该设置仍可用于下次维护。直接显示两个 scope 会让人误以为仍有任务在排队。

## Decisions

- 语义搜索为默认子标签。搜索页以查询、来源和证据原文为主，目录采用可展开的表格。切换子标签保留各自的状态，只在显式浏览、翻页或展开时读取相应数据。
- Host 用库 ID 和条目 key 异步加载需要复核的 Zotero 条目。索引在插件重启后仍可使用，即使条目尚未进入内存。显示标题的读取独立于已经核验的片段。
- 使用原有的向量检索和来源版本、UTF-16 范围校验。sidecar 从同一排名保留最多 25 个备用候选，确认有效的结果达到请求数量后停止复核。完整性和可用性继续通过现有 issues 与 limited 表达。
- 页面本地应用最低相似度。未搜索、无已索引目标、无法评分、来源失效、调用失败和分数过滤各自提供相应反馈。保留可验证的部分结果。
- 库名由 Host 按已发布及目标范围内的 ID 解析。范围比较按库和来源集合及 Topic 开关进行。模型与编码参数的变化单列，构建任务沿用已有维护入口。

## Verification

用已发布的测试库比对索引浏览与查询返回的同一来源。覆盖排在失效命中之后的有效论文、Topic、阈值、归属正确的异步结果，以及宽窄视口、主题和键盘操作。
