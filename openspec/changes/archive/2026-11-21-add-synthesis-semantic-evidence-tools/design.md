# Design

## Context

Rust owns the published vector index and reverse-Host source verification. The Workbench already uses exact scoring and verified previews. Host Bridge and the future Pi tool catalog can consume the production Synthesis client.

## Goals / Non-Goals

Expose retrieval and context expansion with citable provenance. Keep the existing index corpus, no lexical fallback in the semantic operation and no answer generation in Synthesis.

## Decisions

- Share the ranking and verified evidence pipeline between the Workbench explorer and the typed agent port. Retain the Workbench projection and its presentation controls.
- Bind evidence refs to a publication, identity, fragment and version. Read at most three same-group ranges after recapturing current authorization. Let durable source owners validate bytes and locations.
- Return vector coverage and stable reasons. Ship no more than 12 results or 40 KiB to an agent. The Workbench keeps its existing larger display budget.
- Host Bridge CLI and MCP project the same contracts. The Pi catalog can call the same ports on integration.
- Host Bridge semantic baseline is `9e92da609d5c983cae6234bb6c6c800bc8f96de7`. The explicit deletion inventory is empty.

The baseline materialized Minimum skill has 199 substantive lines and 42,696 normalized prose characters. Its direct command catalog has 163 lines and 18,366 characters. The Generic research-synthesis skill has 124 lines and 16,536 characters, and its direct playbook has 166 lines and 11,895 characters. The corresponding inherited Hermes copies have the same values.

The rendered parity review found zero unmapped, downgraded, unauthorized dropped or intra-package duplicate instructions. The relative depth check passed. The two new command cards fall within seven lines of the advisory depth target and cover the full command contract, including input, output, effects and failure recovery. Existing advisory warnings come from byte-identical cards.

## Risks / Trade-offs

Eligible metadata can yield a valid citation with limited knowledge about the paper itself. Raw PDFs without an indexed derivative remain a coverage gap. A changed or suspended source requires a fresh search.
