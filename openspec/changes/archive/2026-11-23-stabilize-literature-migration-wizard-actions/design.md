# Design

Render one action bar immediately after the step navigation. Both rows precede the filters and the scrolling content, so changes in results, progress, or open details leave the actions in place. The right-hand action advances the wizard or opens the existing migration confirmation. The left-hand action returns to the previous step or problem group.

The document drawer has its own return action. Moving to another step or problem group closes the detail from the previous one. Paging within that group preserves the detail.
