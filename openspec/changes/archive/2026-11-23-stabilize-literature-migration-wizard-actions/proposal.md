# Proposal

## Why

The migration wizard puts the overview and final review actions in the footer and the problem actions near the strategies. The user must find the primary action again after changing steps.

## What Changes

- Place all wizard actions in the same bar below the numbered steps and above the filters.
- Keep the bar available when a narrow layout shows document details.
- Keep the existing confirmation before the final migration write.

## Capabilities

### Modified Capabilities

- `literature-artifact-migration` defines a single position for the wizard actions.

## Impact

Dashboard migration layout, navigation tests, and migration guidance.
