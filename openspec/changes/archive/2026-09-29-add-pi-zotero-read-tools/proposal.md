# Proposal

## Why

C12 proves only the current-view Zotero tool. The Built-in Pi Agent Runtime needs the reviewed canonical read surface to inspect library facts and deliver owner-managed files without exposing raw Zotero objects or source paths.

## What Changes

- **BREAKING** Replace the C12 factory's positional broker argument with `{ broker, workspace }`.
- Add thirteen reviewed read definitions, for fourteen total. The later #26 Q98 decision removes the two low-level note payload tools from the earlier C13 plan.
- Project attachment source paths into owner-managed working copies or path-free metadata; deliver annotation export and traversal as managed files.
- Keep admission, authorization, evidence, and final result limits in the existing Tool Gateway.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `pi-zotero-tool-catalog`: Extend the static canonical Broker projection to the approved read catalog and file-delivery semantics.

## Impact

The native catalog factory, its existing shared and Zotero tests, the Pi runtime handoff, and the catalog specification. No new dependencies, Broker changes, or persisted schema.
