# 导出/导入文献包

## 用途

导出和导入包含元数据、标签、子笔记、附件、嵌入图片和条目间关系的 Zotero 父条目便携式 ZIP 包，便于 Zotero 实例间迁移或与其他研究者协作。

## 导出文献包

### 应用场景

- 将选定的 Zotero 条目备份为独立 ZIP
- 与使用不同 Zotero 库的合作者共享文献
- 将条目传输到另一个 Zotero 实例以供稍后导入

### 输入条件

| 条件类型 | 说明 |
|---------|------|
| 输入单元 | 父条目 |
| 选择 | 一个或多个父条目；不可混入附件、笔记和子条目 |
| 输出 | 用户选择 ZIP 保存位置；若缺少 `.zip` 扩展名则自动追加 |

### 工作过程

1. 验证所有选定条目均为父条目（不允许附件、笔记或子条目）。
2. 为每个父条目收集书目元数据、标签、含嵌入图片的子笔记、可读本地附件和链接 URL 附件。
3. 对于 Markdown 附件，将本地图片引用改写为包内相对路径，并包含所引用的图片。
4. 仅记录同一批次导出的父条目之间的条目间关系。
5. 写入 `manifest.json`，包含格式版本、文件清单、完整性数据和导出警告。
6. 将所有内容打包为用户所选位置的 ZIP 文件。

缺失的本地文件会跳过并记录警告；Markdown 中的远程图片保持原样（不下载）。取消保存对话框将取消导出。

### 产物

| 产物 | 说明 |
|----------|-------------|
| `manifest.json` | 格式版本、文件清单、完整性信息、导出警告、条目间关系 |
| 父条目元数据 | 每个父条目的可移植书目信息和标签 |
| 子笔记 | 含嵌入图片的笔记 |
| 附件 | 可读本地附件；含随附本地图片的 Markdown 附件 |
| 链接 URL 附件 | 链接信息 |

## 导入文献包

### 应用场景

- 将先前导出的文献包恢复到当前 Zotero 库
- 导入合作者共享的文献

### 输入条件

| 条件类型 | 说明 |
|---------|------|
| 输入单元 | Workflow（无需选择 Zotero 条目） |
| 导入方式 | 选择由"导出文献包"生成的 ZIP 文件 |
| Collection 上下文 | 若当前视图中选择了实际的 collection，新条目将加入其中；否则条目导入到库根目录 |

### 工作过程

1. 验证包：类型、版本、归档路径、文件清单、大小和完整性。验证失败将中止且不修改库。
2. 为包中的每个父条目创建新的 Zotero 条目图：书目元数据、标签、附件、笔记、嵌入图片和链接 URL 附件。
3. 恢复同一包中成功导入的父条目之间的条目间关系。
4. 若单个父条目导入失败，清理该条目及其新创建的子条目，然后继续处理剩余条目。

导入从不重用原始 Zotero 条目 ID 或 key，从不去重、合并或覆盖现有条目。重新导入同一包将生成独立副本。

### 产物

包含完整条目图的新 Zotero 父条目。缺失文件、清理失败或关系恢复失败将作为警告报告；结果可能部分完成。

## 预计耗时

取决于条目数量、附件大小和本地磁盘速度。纯元数据或小笔记可快速完成；大型 PDF 或大量图片会按比例增加耗时。

## 依赖

- 无需后端连接
- 仅依赖 Zotero 本地存储和文件访问权限
