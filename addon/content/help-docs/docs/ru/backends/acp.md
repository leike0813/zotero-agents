# Конфигурация бэкенда ACP

## Что такое ACP?

ACP (Agent Client Protocol) — это протокол для взаимодействия с бэкендами агентов. Zotero Agents взаимодействует с локально запущенными процессами агентов (такими как Codex, Claude Code, OpenCode и т.д.) через протокол ACP для обеспечения диалогов и выполнения навыков.

Бэкенд ACP — это **рекомендуемый** способ настройки — если у вас установлен любой совместимый с ACP инструмент агента на вашем компьютере, вы можете использовать его напрямую без дополнительной настройки.

## Впервые с Agent?

Если вы впервые работаете с инструментами Agent и не знаете, какой выбрать или как установить, обратитесь к этому руководству:

**[Руководство по началу работы с Agent](https://agent.ps5.online)**

## Почему сначала ACP?

- **Нулевая нагрузка по настройке**: Не нужно развёртывать дополнительные сервисы; используйте инструменты агентов, уже имеющиеся на вашем компьютере
- **Автоматическое управление процессами**: Плагин указывает команду запуска в конфигурации и автоматически управляет жизненным циклом процесса агента
- **Поддержка нескольких агентов**: Настройте несколько различных бэкендов агентов одновременно и переключайтесь между ними по мере необходимости
- **Изоляция конфигурации**: Некоторые агенты (такие как OpenCode и Codex) поддерживают изоляцию каталогов конфигурации и каталогов постоянных сессий через переменные окружения

## Шаги настройки

1. Убедитесь, что у вас установлен хотя бы один совместимый с ACP инструмент агента CLI на вашем компьютере
2. Откройте **Инструменты → [Менеджер бэкендов](#doc/backends%2Fbackend-manager)**
3. Переключитесь на вкладку **ACP**
4. Выберите ваш инструмент агента из выпадающего списка **Добавить из пресета** или нажмите **Добавить ACP** для ручной настройки
5. Заполните следующие поля:
   - **Отображаемое имя**: Понятное имя (например, "Мой OpenCode")
   - **Команда**: Команда для запуска бэкенда ACP (пресеты заполняют автоматически, но вы также можете изменить вручную)
   - **Аргументы**: Дополнительные аргументы для команды (необязательно)
   - **Переменные окружения**: Дополнительные переменные окружения (необязательно, используются для изоляции конфигурации и т.д.)
6. Нажмите **Сохранить** в правом нижнем углу

### Проверка подключения

После сохранения плагин автоматически обнаруживает возможности бэкенда:

- Проверяет существование команды
- Подключается и инициализируется
- Получает список доступных моделей и режимов
- Вычисляет отпечаток конфигурации для обнаружения последующих изменений

Если обнаружение не удалось, проверьте, что CLI агента установлен правильно и формат команды верен.

## Поддерживаемые пресеты агентов

Плагин предоставляет несколько встроенных пресетов. После нажатия **Добавить из пресета** выберите агента слева; справа отображаются параметры запуска и предварительный просмотр конфигурации только для чтения.

**Запустить через npx** переключает команду на формат `npx <package>` и показывает уведомление о необходимости установки Node.js и npm. Codex, Claude Code, Factory Droid, Pi ACP и Amp ACP по умолчанию используют npx; остальные пресеты по умолчанию используют установленную команду. При включении npx к отображаемому имени профиля добавляется суффикс `(npm)`.

Отключение **Запустить через npx** запускает именованный исполняемый файл пресета, который должен быть уже установлен (например, `gemini`, `copilot`, `opencode` или `kimi`). Пресеты без опции npx всегда используют установленный CLI: Hermes, нативный Cursor (`agent`), Mistral Vibe, OpenHands, Goose, Junie, Kiro CLI и Oh My Pi. Pi ACP и Amp ACP — это адаптеры, поэтому базовые CLI Pi и Amp также должны быть установлены и аутентифицированы. Oh My Pi основан на Bun. Для включения npx требуются Node.js и npm.

**Изолированная среда** доступна только для агентов, поддерживающих изоляцию. При включении плагин добавляет в предварительный просмотр задокументированные переменные окружения изоляции или аргументы каталога сессии и показывает уведомление о том, что параметры агента и аутентификацию необходимо управлять самостоятельно в этом каталоге. При включении изоляции к отображаемому имени профиля добавляется суффикс `(Isolated)`.

После выбора пресета вы всё ещё можете вручную изменить любое поле.

## Рекомендации по настройке переменных окружения

Некоторые агенты поддерживают изоляцию конфигурации и постоянные сессии через переменные окружения или аргументы команды. Пресеты с включённой **Изолированной средой** автоматически добавляют документированные значения; для ручных профилей добавьте соответствующие значения самостоятельно:

Изоляция переносит только объявленные корни файловой системы. Изоляция Amp ACP затрагивает только состояние потоков/сессий адаптера, тогда как конфигурация и учётные данные Amp настраиваются независимо. Нативная изоляция Cursor затрагивает каталог конфигурации Cursor, отдельный от каталога сессий адаптера `cursor-agent-acp`. Собственный кэш Copilot и связка ключей Goose остаются вне добавляемых путей.

Пресеты OpenCode и Kilo также всегда добавляют встроенную конфигурацию разрешений: `OPENCODE_CONFIG_CONTENT` и `KILO_CONFIG_CONTENT` соответственно, обе со значением `{"permission":{"question":"deny"}}`. Вы можете изменить или удалить эти значения после добавления пресета.

## Бесплатные модели

Несколько движков предлагают **бесплатный доступ к моделям** — идеально для начала без оплаты:

| Движок                    | Бесплатная опция             | Как это работает                                                                                                                                                                             |
| ------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Kilo Code**             | Режим Auto Free              | Встроенный режим Auto Free в Kilo Code автоматически направляет каждый запрос к подходящей бесплатной модели. Включите в настройках Kilo Code — ключ API не требуется                        |
| **OpenCode Zen**          | Встроенные бесплатные модели | Версия [OpenCode Zen](https://opencode.ai/zen) включает бесплатный доступ к моделям без подписки API                                                                                         |
| **OpenCode + OpenRouter** | Бесплатные модели OpenRouter | Настройте OpenCode на использование [OpenRouter](https://openrouter.ai/) и выберите бесплатные модели (напр., Gemini 2.5 Flash, DeepSeek V3). Требуется бесплатная учётная запись OpenRouter |

### Ограничения бесплатного тарифа

Бесплатных моделей достаточно для эпизодического использования, но учитывайте следующие ограничения:

| Ограничение                     | Чего ожидать                                                                                                                                          |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ограничение скорости**        | Запросы могут замедляться — обычно 5–20 запросов в минуту в зависимости от нагрузки провайдера. Пакетная обработка значительно замедляется            |
| **Параллельность**              | Обычно ограничено одним одновременным запросом. Одновременный запуск нескольких рабочих процессов может поставить их в очередь или привести к сбою    |
| **Доступность моделей**         | Пулы бесплатных моделей могут быть исчерпаны в часы пик. Возможны ошибки «модель недоступна» или «превышена ёмкость»                                  |
| **Смена моделей**               | Провайдеры могут незаметно заменять бесплатные модели (повышение или понижение) без предупреждения. Качество вывода может различаться между запусками |
| **Отсутствие SLA / Надёжность** | Бесплатные тарифы не гарантируют доступность. Сервисы могут быть временно недоступны или прекращены                                                   |

> Если вам нужна надёжная пакетная обработка или промышленное использование, рассмотрите платный план, например [OpenCode Go](https://opencode.ai/go?ref=SZDFT9GZKW) ($10/мес.) или Coding Plan (Bailian, Zhipu и др.). Стоимость одной статьи ничтожна по сравнению с экономией времени.

## Типы запросов

Бэкенд ACP поддерживает два типа запросов:

- `acp.prompt.v1` — Диалоговое взаимодействие (ACP Чат)
- `acp.skill.run.v1` — Выполнение навыков (Навыки ACP)

Один и тот же бэкенд ACP может использоваться как для диалогов, так и для запусков навыков одновременно.

## Управление сессиями

- Каждый бэкенд может иметь несколько сессий (диалогов), которые постоянно хранятся в базе данных плагина
- Различные бэкенды ACP могут работать одновременно, не мешая друг другу
- Сессиями можно управлять в [ACP Чате](#doc/sidebar%2Facp-chat)
