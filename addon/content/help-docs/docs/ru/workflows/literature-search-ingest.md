# Literature Search & Ingest

## Назначение

Поиск академической литературы с помощью ИИ и приём утверждённых результатов непосредственно в Zotero. Пустой запрос может начатьguided диалог, который превращает исследовательскую потребность в подтверждённый поисковый бриф.

## Режимы поиска

| Режим | Описание |
|------|------|
| `auto` | Определяет подходящий режим для непустого запроса; пустой запрос запускает guided планирование. |
| `guided` | Уточнить исследовательскую потребность, проверить локальное покрытие Zotero/Synthesis и выполнить подтверждённый бриф напрямую. |
| `topic_expansion` | Поиск по направлению исследования или теме. |
| `paper_seed_expansion` | Расширение от статьи-затравки. |
| `targeted_ingest` | Точный поиск и приём одной статьи. |

## Поток выполнения

```
1. Guided планирование (пустой auto запрос или guided режим)
    └── Уточнить исследовательскую цель в коротких раундах
    └── Читать только локальное покрытие Zotero/Synthesis
    └── Представить структурированный поисковый бриф
    └── Ждать подтверждения; никакого веб-поиска или записи до подтверждения

2. Поиск и выбор кандидатов
    └── Поиск согласно подтверждённому брифу или явному режиму
    └── Проверить идентификаторы, авторитетные метаданные, целевые страницы и доказательства легального публичного PDF
    └── Пользователь выбирает статьи для приёма

3. Приём и завершение
    └── Принять каждую утверждённую статью через zotero-bridge
    └── Вывести краткий JSON приёма, включая ссылки на отсутствующие PDF
```

## Параметры

| Параметр | Тип | Описание | По умолчанию |
|------|------|------|------|
| `query` | string | Тема поиска, идентификатор статьи, затравка или пустое значение для guided планирования. | Пусто |
| `searchMode` | string | `auto`, `guided`, `topic_expansion`, `paper_seed_expansion` или `targeted_ingest`. | `auto` |
| `targetCollection` | string | Необязательная целевая коллекция. | Пусто |

## Вывод

- Доказательства кандидата проверяются до того, как пользователь может одобрить приём.
- Каждый успешный приём создаётся или повторно используется в Zotero; легальные ссылки на целевые страницы остаются доступными, когда PDF не прикреплён.
- Guided запуски сообщают `search_mode: "guided"`; другие запуски сохраняют свой конкретный режим поиска.

## Зависимости

- **Бэкенд**: ACP бэкенд с интерактивным выполнением
