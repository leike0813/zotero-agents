# Export/Import Literature Bundle

## Назначение

Экспорт и импорт портативных ZIP-пакетов родительских элементов Zotero с их метаданными, тегами, дочерними заметками, вложениями, встроенными изображениями и межэлементными связями, облегчая миграцию между экземплярами Zotero или сотрудничество с другими исследователями.

## Export Literature Bundle

### Варианты использования

- Резервное копирование выбранных элементов Zotero в виде автономного ZIP
- Обмен литературой с сотрудниками, использующими другую библиотеку Zotero
- Передача элементов в другой экземпляр Zotero для последующего импорта

### Ограничения ввода

| Тип ограничения | Описание |
|---------|------|
| Единица ввода | Родительский элемент |
| Выбор | Один или несколько родительских элементов; вложения, заметки и дочерние элементы не могут быть смешаны |
| Вывод | Пользователь выбирает место сохранения ZIP; расширение `.zip` добавляется автоматически, если отсутствует |

### Поведение

1. Проверить, что все выбранные элементы являются родительскими элементами (вложения, заметки или дочерние элементы не допускаются).
2. Собрать библиографические метаданные, теги, дочерние заметки со встроенными изображениями, читаемые локальные вложения и вложения URL-ссылок для каждого родительского элемента.
3. Для вложений Markdown переписать локальные ссылки на изображения в пути относительно пакета и включить указанные изображения.
4. Записывать межэлементные связи только между родительскими элементами, экспортированными в одном пакете.
5. Записать `manifest.json` с версией формата, инвентаризацией файлов, данными целостности и любыми предупреждениями об экспорте.
6. Упаковать все в ZIP-файл в выбранном пользователем месте.

Отсутствующие локальные файлы пропускаются с предупреждением; удаленные изображения в Markdown сохраняются как есть (не загружаются). Отмена диалога сохранения отменяет экспорт.

### Вывод

| Артефакт | Описание |
|----------|-------------|
| `manifest.json` | Версия формата, инвентаризация файлов, информация о целостности, предупреждения об экспорте, межэлементные связи |
| Метаданные родительского элемента | Портативная библиографическая информация и теги для каждого родительского элемента |
| Дочерние заметки | Заметки со встроенными изображениями |
| Вложения | Читаемые локальные вложения; вложения Markdown с сопутствующими локальными изображениями |
| Вложения URL-ссылок | Информация о ссылках |

## Import Literature Bundle

### Варианты использования

- Восстановить ранее экспортированный пакет литературы в текущую библиотеку Zotero
- Импортировать литературу, которой поделился сотрудник

### Ограничения ввода

| Тип ограничения | Описание |
|---------|------|
| Единица ввода | Workflow (выбор элементов Zotero не требуется) |
| Метод импорта | Выбрать ZIP-файл, созданный Export Literature Bundle |
| Контекст коллекции | Если в текущем виде выбрана реальная коллекция, новые элементы добавляются в нее; в противном случае элементы импортируются в корень библиотеки |

### Поведение

1. Проверить пакет: тип, версия, пути архива, инвентаризация файлов, размер и целостность. Сбой проверки прерывает без изменения библиотеки.
2. Для каждого родительского элемента в пакете создать новый граф элементов Zotero: библиографические метаданные, теги, вложения, заметки, встроенные изображения и вложения URL-ссылок.
3. Восстановить межэлементные связи между успешно импортированными родительскими элементами из одного пакета.
4. Если один родительский элемент не удается импортировать, очистить этот элемент и его вновь созданные дочерние элементы, затем продолжить с оставшимися элементами.

Импорт никогда не повторно использует исходные ID или ключи элементов Zotero, никогда не дедуплицирует, не объединяет и не перезаписывает существующие элементы. Повторный импорт одного и того же пакета создает независимые копии.

### Вывод

Новые родительские элементы Zotero с их полными графами элементов. Отсутствующие файлы, сбои очистки или сбои восстановления связей сообщаются как предупреждения; результат может быть частично завершен.

## Ожидаемая продолжительность

Зависит от количества элементов, размеров вложений и скорости локального диска. Чистые метаданные или небольшие заметки завершаются быстро; большие PDF или много изображений увеличивают продолжительность пропорционально.

## Зависимости

- Подключение к бэкенду не требуется
- Зависит только от локального хранилища Zotero и разрешений на доступ к файлам
