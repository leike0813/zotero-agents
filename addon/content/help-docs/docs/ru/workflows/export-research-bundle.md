# Export Research Bundle

## Назначение

Автоматическая сборка пакета исследования только для чтения в Dashboard Products из существующей библиотеки Zotero и контекста Synthesis на основе объявленного намерения статьи. Пакет собирает релевантные темы, основные статьи и связанные статьи с их доступными артефактами анализа.

## Ввод

| Параметр | Обязательно | Описание |
| --- | --- | --- |
| `paperTitle` | Да | Рабочий заголовок рукописи, используемый для поиска исследовательских материалов. |
| `researchContent` | Да | Исследовательская проблема, методы, область и предполагаемый вклад. |
| `articleType` | Нет | Тип рукописи (по умолчанию: `original research`). |
| `maxTopics` | Нет | Максимальное количество релевантных тем для включения, диапазон 0–5 (по умолчанию: 5). |
| `maxCorePapers` | Нет | Максимальное количество основных статей, диапазон 1–20 (по умолчанию: 20). |
| `maxRelatedPapers` | Нет | Максимальное общее количество связанных статей, включая основные, диапазон 1–80 (по умолчанию: 80). |

Выбор элементов Zotero не требуется.

## Поведение

1. Получить параметры намерения статьи от пользователя.
2. Обнаружить материалы-кандидаты из существующих Synthesis Topics, элементов библиотеки Zotero и доступного контекста графа цитирования.
3. Выполнить ограниченную оценку, чтобы отличить основные статьи от связанных.
4. Собрать пакет исследования с отчетами по темам, библиографическими метаданными и доступными артефактами анализа v2 (дайджесты, ссылки, анализы цитирования, содержимое разговоров).
5. Для основных статей предпочитать источник Markdown с локальными изображениями; откатываться к PDF; записывать предупреждение, если ни один недоступен.
6. Зарегистрировать пакет как продукт только для чтения в Dashboard Products.

Недоступность темы, графа, артефакта анализа или источника элегантно деградирует — workflow продолжает работу с любыми доказательствами, которые все еще читаемы, и записывает диагностику и предупреждения. Если ни одна статья не соответствует критериям, запуск завершается без регистрации продукта.

## Вывод и применение

Пакет исследования регистрируется в Dashboard Products как артефакт только для чтения. Его структура:

| Путь | Описание |
|------|-------------|
| `README.md` | Точка входа для агентов и людей с рекомендуемым порядком чтения, именованием файлов, индексом тем/статей |
| `manifest.json` | Машиночитаемый инвентарь путей артефактов v2, происхождения, целостности файлов и диагностики |
| `topics/<topic-id>/report.md` | Отчет синтеза темы (когда доступен) |
| `papers/<paper-id>/metadata.json` | Портативные библиографические метаданные для каждой статьи |
| `papers/<paper-id>/source.md` | Источник Markdown (когда доступен) |
| `papers/<paper-id>/digest-*.md` | Артефакты дайджеста Literature Analysis (когда доступны) |

Только семантические каталоги `topics/` и `papers/` используются вместе с корневыми файлами. Изображения Markdown включаются только тогда, когда их разрешенный локальный путь находится в дереве каталогов файла Markdown; внетreeевые или отсутствующие изображения сохраняют свои исходные ссылки, но не регистрируются как файлы продукта.

## Ожидаемая продолжительность

Зависит от размера библиотеки, количества кандидатов, доступности тем/графа и скорости ответа бэкенда. Прогресс и результаты видны на панели выполнения.

## Рекомендация модели

Рекомендуется модель с сильным семантическим пониманием и способностью вызова инструментов. Задача требует оценки релевантности тем и статей по отношению к намерению статьи и правильного использования контекста Zotero и Synthesis только для чтения.

## Зависимости

- **Бэкенд**: Skill-Runner
- **Навык**: `export-research-bundle`
- **Host Bridge**: Требуется разрешение на чтение контекста Zotero и Synthesis
