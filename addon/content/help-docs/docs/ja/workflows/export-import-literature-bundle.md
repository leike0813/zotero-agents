# Export/Import Literature Bundle

## 目的

Zotero の親アイテムのメタデータ、タグ、子ノート、添付ファイル、埋め込み画像、アイテム間関係を含むポータブル ZIP バンドルをエクスポートおよびインポートし、Zotero インスタンス間の移行や他の研究者との共同作業を容易にします。

## Export Literature Bundle

### ユースケース

- 選択した Zotero アイテムを自己完結型 ZIP としてバックアップ
- 別の Zotero ライブラリを使用する共同研究者と文献を共有
- 後でインポートするためにアイテムを別の Zotero インスタンスに転送

### 入力制約

| 制約タイプ | 説明 |
|---------|------|
| 入力ユニット | 親アイテム |
| 選択 | 1 つ以上の親アイテム。添付ファイル、ノート、子アイテムを混在させることはできません |
| 出力 | ユーザーが ZIP 保存場所を選択します。`.zip` 拡張子が欠落している場合は自動的に追加されます |

### 動作

1. 選択されたすべてのアイテムが親アイテムであることを検証します（添付ファイル、ノート、子アイテムは許可されません）。
2. 各親アイテムの書誌メタデータ、タグ、埋め込み画像付き子ノート、読み取り可能なローカル添付ファイル、リンク URL 添付ファイルを収集します。
3. Markdown 添付ファイルの場合、ローカル画像参照をバンドル相対パスに書き換え、参照された画像を含めます。
4. 同じバッチでエクスポートされた親アイテム間のアイテム間関係のみを記録します。
5. フォーマットバージョン、ファイルインベントリ、整合性データ、およびエクスポート警告を含む `manifest.json` を書き込みます。
6. ユーザーが選択した場所に ZIP ファイルとしてすべてをパッケージ化します。

欠落しているローカルファイルは警告付きでスキップされます。Markdown 内のリモート画像はそのまま保持されます（ダウンロードされません）。保存ダイアログをキャンセルするとエクスポートがキャンセルされます。

### 出力

| アーティファクト | 説明 |
|----------|-------------|
| `manifest.json` | フォーマットバージョン、ファイルインベントリ、整合性情報、エクスポート警告、アイテム間関係 |
| 親アイテムのメタデータ | 親ごとのポータブルな書誌情報とタグ |
| 子ノート | 埋め込み画像付きノート |
| 添付ファイル | 読み取り可能なローカル添付ファイル。付随するローカル画像付き Markdown 添付ファイル |
| リンク URL 添付ファイル | リンク情報 |

## Import Literature Bundle

### ユースケース

- 以前にエクスポートした文献バンドルを現在の Zotero ライブラリに復元
- 共同研究者が共有した文献をインポート

### 入力制約

| 制約タイプ | 説明 |
|---------|------|
| 入力ユニット | ワークフロー（Zotero アイテムの選択は不要） |
| インポート方法 | Export Literature Bundle によって生成された ZIP ファイルを選択 |
| コレクションコンテキスト | 現在のビューで実際のコレクションが選択されている場合、新しいアイテムがそこに追加されます。それ以外の場合、アイテムはライブラリルートにインポートされます |

### 動作

1. バンドルを検証します：タイプ、バージョン、アーカイブパス、ファイルインベントリ、サイズ、整合性。検証の失敗はライブラリを変更せずに中止します。
2. バンドル内の各親アイテムについて、新しい Zotero アイテムグラフを作成します：書誌メタデータ、タグ、添付ファイル、ノート、埋め込み画像、リンク URL 添付ファイル。
3. 同じバンドルから正常にインポートされた親アイテム間のアイテム間関係を復元します。
4. 単一の親アイテムのインポートに失敗した場合、そのアイテムと新しく作成された子をクリーンアップし、残りのアイテムで続行します。

インポートは元の Zotero アイテム ID またはキーを再利用せず、既存のアイテムを重複排除、マージ、または上書きすることはありません。同じバンドルを再インポートすると、独立したコピーが生成されます。

### 出力

完全なアイテムグラフを持つ新しい Zotero 親アイテム。欠落ファイル、クリーンアップの失敗、または関係の復元の失敗は警告として報告されます。結果は部分的に完了している可能性があります。

## 推定所要時間

アイテム数、添付ファイルのサイズ、ローカルディスクの速度によって異なります。純粋なメタデータまたは小さなノートはすぐに完了します。大きな PDF や多数の画像は比例して時間を増加させます。

## 依存関係

- バックエンド接続不要
- Zotero ローカルストレージとファイルアクセス権限にのみ依存
