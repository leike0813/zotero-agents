# Literature Search & Ingest

## 目的

AI を使用して学術文献を検索し、承認された結果を Zotero に直接取り込みます。空のクエリは、研究ニーズを確認済みの検索ブリーフに変換するガイド付き会話を開始できます。

## 検索モード

| モード | 説明 |
|------|------|
| `auto` | 非空クエリに適したモードを検出します。空のクエリはガイド付き計画を開始します。 |
| `guided` | 研究ニーズを明確にし、ローカルの Zotero/Synthesis カバレッジを検査し、確認済みブリーフを直接実行します。 |
| `topic_expansion` | 研究方向またはトピックで検索します。 |
| `paper_seed_expansion` | シード論文から拡張します。 |
| `targeted_ingest` | 1 篇の論文を正確に特定して取り込みます。 |

## 実行フロー

```
1. ガイド付き計画（空の auto クエリまたは guided モード）
    └── 短いラウンドで研究目標を明確にする
    └── ローカルの Zotero/Synthesis カバレッジのみ読み取る
    └── 構造化された検索ブリーフを提示する
    └── 確認を待つ。確認前にウェブ検索や書き込みは行わない

2. 候補検索と選択
    └── 確認済みブリーフまたは明示的モードに従って検索
    └── 識別子、権威あるメタデータ、ランディングページ、合法な公開 PDF 証拠を検証
    └── ユーザーが取り込む論文を選択

3. 取り込みと完了
    └── zotero-bridge を通じて承認された各論文を取り込む
    └── PDF 欠落リンクを含む簡潔な取り込み JSON を出力
```

## パラメータ

| パラメータ | タイプ | 説明 | デフォルト |
|------|------|------|------|
| `query` | string | 検索トピック、論文識別子、シード、またはガイド付き計画用の空値。 | 空 |
| `searchMode` | string | `auto`、`guided`、`topic_expansion`、`paper_seed_expansion`、`targeted_ingest`。 | `auto` |
| `searchBreadth` | string | 幅広い複数経路の探索、バランスの取れた網羅性、または迅速な初回検索を選択します。 | `broad` |
| `languageHints` | string[] | `en`、`zh-CN`、`ja`、`de` などの任意の BCP 47 言語ヒント。クエリと情報源を広げますが、他の言語を除外しません。 | `[]` |
| `targetCollection` | string | オプションのターゲットコレクション。 | 空 |

## 出力

- ユーザーが取り込みを承認する前に候補証拠が検証されます。
- 成功した取り込みはそれぞれ Zotero に作成または再利用されます。PDF が添付されていない場合も合法なランディングページリンクが利用可能です。
- ガイド付き実行は `search_mode: "guided"` を報告します。他の実行は具体的な検索モードを保持します。
