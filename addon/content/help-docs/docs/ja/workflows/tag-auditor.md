# Tag Auditor

## 目的

Zotero ライブラリ内のすべてのトップレベル通常アイテムを統制タグ語彙に対してスキャンし、アイテムごとのタグ適合性を報告します。結果は Synthesis Workbench のタグ監査パネルに書き込まれ、レビューと後続の正規化に使用されます。

## 入力

パラメータも Zotero アイテムの選択も不要です。ワークフローはライブラリ全体を操作します。

## 動作

1. `exportTagVocabularyForRegulator` を通じて Synthesis から統制タグ語彙を読み込みます。
2. ライブラリ内のすべてのトップレベル通常アイテムをページングします（子アイテム、ノート、添付ファイル、削除済みアイテムを除く）。
3. 各アイテムについて、現在のタグを収集し適合性を評価します。統制語彙に存在しないタグは非適合です。
4. 監査エントリをライブラリ ID ごとにグループ化し、`replaceTagAuditRecords` を通じて Synthesis に書き込みます。

ワークフローは完全に自動であり、Zotero のアイテムやタグを変更しません。タグパネル用の監査レコードを生成する読み取り専用スキャンです。

## 出力と適用

Synthesis Workbench のタグ監査パネルには、各アイテムの監査レコードが表示されます。各レコードには以下が含まれます：

| フィールド | 説明 |
|-------|-------------|
| `itemKey` | Zotero アイテムキー |
| `compliant` | アイテムのすべてのタグが統制語彙内にあるかどうか |
| `nonCompliantTags` | 統制語彙に見つからないタグのリスト |

実行結果には、監査されたアイテム数とライブラリごとのタグ正規化が必要なアイテム数の要約が含まれます。ワークフローを再度実行すると、以前の監査レコードが置き換えられます（同じ語彙状態内で冪等）。

前提条件として、統制タグ語彙が Synthesis Workbench のタグページですでに定義されている必要があります。

## 依存関係

- バックエンド接続不要
- **統制語彙**：統制タグ語彙を最初に定義する必要があります。[タグ管理](#doc/synthesis%2Ftags)を参照
