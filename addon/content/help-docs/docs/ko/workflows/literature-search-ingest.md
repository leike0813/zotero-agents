# Literature Search & Ingest

## 목적

AI로 학술 문헌을 검색하고 승인된 결과를 Zotero로 직접 수집합니다. 빈 쿼리는 연구 요구를 확인된 검색 브리프로 전환하는 가이드 대화를 시작할 수 있습니다.

## 검색 모드

| 모드 | 설명 |
|------|------|
| `auto` | 비어 있지 않은 쿼리에 적합한 모드를 감지합니다. 빈 쿼리는 가이드 계획을 시작합니다. |
| `guided` | 연구 요구를 명확히 하고, 로컬 Zotero/Synthesis 커버리지를 검사하고, 확인된 브리프를 직접 실행합니다. |
| `topic_expansion` | 연구 방향 또는 주제별 검색. |
| `paper_seed_expansion` | 시드 논문에서 확장. |
| `targeted_ingest` | 단일 논문을 정확하게 찾고 수집. |

## 실행 흐름

```
1. 가이드 계획 (빈 auto 쿼리 또는 guided 모드)
    └── 짧은 라운드로 연구 목표 명확히 하기
    └── 로컬 Zotero/Synthesis 커버리지만 읽기
    └── 구조화된 검색 브리프 제시
    └── 확인 대기; 확인 전 웹 검색이나 쓰기 없음

2. 후보 검색 및 선택
    └── 확인된 브리프 또는 명시적 모드에 따라 검색
    └── 식별자, 권위 있는 메타데이터, 랜딩 페이지 및 합법적 공개 PDF 증거 검증
    └── 사용자가 수집할 논문 선택

3. 수집 및 완료
    └── zotero-bridge를 통해 승인된 각 논문 수집
    └── PDF 누락 링크를 포함한 간결한 수집 JSON 출력
```

## 파라미터

| 파라미터 | 유형 | 설명 | 기본값 |
|------|------|------|------|
| `query` | string | 검색 주제, 논문 식별자, 시드 또는 가이드 계획을 위한 빈 값. | 비어 있음 |
| `searchMode` | string | `auto`, `guided`, `topic_expansion`, `paper_seed_expansion` 또는 `targeted_ingest`. | `auto` |
| `targetCollection` | string | 선택적 대상 컬렉션. | 비어 있음 |

## 출력

- 사용자가 수집을 승인하기 전에 후보 증거가 검증됩니다.
- 각 성공적인 수집은 Zotero에 생성되거나 재사용됩니다. PDF가 첨부되지 않은 경우에도 합법적 랜딩 페이지 링크가 유지됩니다.
- 가이드 실행은 `search_mode: "guided"`를 보고합니다. 다른 실행은 구체적인 검색 모드를 유지합니다.
