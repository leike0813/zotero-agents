# Export Research Bundle

Runs without a Zotero selection. Enter a manuscript title, article type, and research content. The agent selects related Topic Synthesis topics and Zotero papers, then the host registers one read-only Research Bundle in Dashboard Products.

Discovery is automatic and recoverable. The workflow searches the current library, combines existing Topic sources with citation-graph neighbors, assesses a bounded candidate set, and records how every related or core paper was selected. Missing Topic, graph, or optional source material is reported without changing Zotero or Synthesis state.

The Product contains topic reports, metadata for every related paper, source Markdown or PDF for core papers, and every available v2 literature-analysis or conversation payload. It does not create a ZIP, mutate Synthesis state, or provide a Zotero import contract.
