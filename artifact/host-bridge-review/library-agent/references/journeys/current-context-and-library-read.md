# 当前上下文与文献库读取

当请求提及"本文献"、当前选择、集合、书目候选项或一个已知的 Zotero 条目时使用本旅程。

## 路由

1. 使用 `context current` 和 `context selection get` 解析指示性语言。保留返回的有序顶层条目引用；不要从标题重建 key。
2. 使用 `library item search` 获取有限的按相关性排序的候选集。使用 `library items list` 获取确定性的集合/标签/类型清单，并逐页处理每个 `nextCursor`。
3. 仅在选择一个稳定条目引用后使用 `library item get`。将 `item notes` 和 `item attachments` 作为独立的子集合读取。
4. 报告 key、文献库 id、使用的过滤器、分页完成情况和精确的当前上下文证据。

## 分支与近似匹配

- 搜索结果是候选项，不是权威的完整集合。在报告详细元数据之前先获取所选条目。
- `library snapshot` 用于构建本地元数据镜像；它不能替代当前条目读取。
- 导航命令更改可见的 Zotero UI 但不变更书目数据。仅在用户要求打开已知对象时使用。
- 如果选中的引用是笔记或附件，在 workflow 选择或父条目报告之前规范化为其顶层父条目。

## 故障恢复

选择为空时，请求显式的条目/集合，或仅在请求独立于 UI 上下文时继续。引用过期时，重新读取当前上下文或搜索候选项；绝不猜测其他 key。分页失败时，保留已接受的页并从最后一个游标恢复。
