# Synthesis 研究上下文

将 Synthesis 命令用于派生的研究结构，而非作为实时 Zotero 变更证据。

## 选择模型

- 主题：列出主题、按论文引用查找成员，然后读取单个主题的上下文/报告/审查输入。
- 图谱概览：分页的全局摘要。切片：一致的有界邻域。布局：持久化坐标。指标：所选论文的指标行。查询聚类：主题范围的聚类。排名命令：外部引用与文献库论文。刷新指标：需 approval 的修复，不是读取。
- 文献库/参考文献索引：分页的派生索引记录。Resolver：将标签、集合或论文引用选择器转换为有界的论文集合。关注队列：排序的聚合审查候选项。
- 制品清单：发现文献所属的文件。制品读取：所选内容。导出过滤：文件交付。解析主题摘要：选择与主题论文关联的 digest。
- 概念和模式（schema）命令暴露 typed 语义模型；它们不搜索原始 Zotero 元数据。

## 证据与新鲜度

记录主题 id、论文引用、图谱/索引游标完成情况、resolver 选择器和 combine 模式、制品名称/校验和以及模型/模式标识符。在报告当前选择、附件、Product、权限或写回事实之前，通过对应的实时 Host Bridge 命令确认。

## 恢复

当派生视图看起来过期时，检查 `synthesis cache status` 和 `synthesis index status`。不要仅因为查询无匹配就使缓存失效或刷新图谱指标。仅在诊断识别了受影响的范围且用户可以审查效果时才建议维护。
