# Zotero Agent 独立配置窗口：第二版评审

本版资产：[第二版交互原型](revision-2.html)。第一轮三方案保留在 [revision-1.html](revision-1.html)。当前迭代见 [index.html](index.html)。

本版问题：首次引导与连接工作台组合后，默认模型用途直接放入模型配置卡片，是否方便用户完成首次设置和日常调整？

## 用户已确认的方向

- 独立配置窗口，内部使用左侧导航；prefs 后端区域的新入口在既有后端管理器按钮左侧。
- 保留首次引导，日常采用连接工作台。
- 默认模型不再占据独立页面，合并到工作台配置卡片。
- 同一账户或 API Key 连接一次，之后可以分别使用该连接下的多个模型。

## 本版待评审的交互细节

- 工作台左列选择连接，右侧展示账户状态、模型卡片及连接操作。
- 每张模型卡片可以设置常用、会话、工作流、会话标题用途；点击用途即保存，并在窗口状态栏显示结果。
- 每种用途只有一个全局选择。跨连接设置某个用途时替换该用途的前一个选择，保留其他用途。
- 会话和工作流未单独选择时跟随常用；再次点击单独设置的用途恢复跟随。标题用途再次点击时关闭自动标题。
- 顶部汇总当前各用途的有效模型和连接；点击摘要定位连接。摘要提供查看和跳转，配置操作由模型卡片承担。
- 推理级别由对应连接的模型卡片设置。示例轻量模型没有推理级别。
- 正常账户管理默认收起；登录、授权、欢迎确认和额度暂停等异常状态展开处理入口。
- 会话选择可以覆盖默认模型，不修改全局用途。连接保存不会自动选择常用模型。

## 建议走查

1. 首次使用：ChatGPT 登录 → 模拟登录成功 → 确认使用方案 → 保存连接 → 在 Alpha 卡片设置常用。
2. 同一连接：让 Alpha 用于常用、Beta 用于工作流；再取消工作流单独选择，查看跟随关系。
3. 多连接：选择“日常使用”场景，在个人连接设置会话模型，再把研究连接的模型设为常用，检查会话选择保留。
4. 暂停与恢复：选择额度暂停场景，查看保留的用途及禁用操作；部分响应不解除暂停，实际完成的模拟探测解除暂停。
5. 切换 900 × 600 与深色主题，检查详情独立滚动、下方卡片和窗口入口。

## 实施边界

原型源位于 `src/dashboard/prototypes/`，仅由 `scripts/internal/build-builtin-agent-settings-prototype.mjs` 构建为独立 HTML。没有生产入口，也没有真实网络、持久化、真实账户或 API Key。

本版用途保存、取消和推理设置等细节是评审提案；正式状态、操作与持久化契约由后续 Wayfinder 决策票确认。原型的浏览器走查不能替代 Zotero 实机、ChatGPT 登录或 SIWC 验收。
