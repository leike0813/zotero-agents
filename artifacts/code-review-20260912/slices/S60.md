### F14 [P3][正确性] topic.rs:1116-1124 —— `shutdown` 可能在 drain 已完成时返回 `topic_drain_timeout`
- 证据：
  ```rust
  let (active, wait) = self
      .drained
      .wait_timeout_while(active, timeout, |active| *active > 0)
      .map_err(|_| "topic_drain_failed".to_owned())?;
  ```

- 分析：`wait_timeout_while` 返回的 `WaitTimeoutResult` 可能为 `timed_out() == true`，而其返回值守卫在重新检查谓词后已经显示 `*active == 0`（最后一个 `ActiveApply::drop` 在等待者重新拿锁前完成递减+notify）。此时 `*active > 0` 已经足够作为唯一判据（守卫是权威状态），`|| wait.timed_out()` 反而把“已经排空”误报为超时。对比 `admission.rs:77` 同样拿到守卫却写成 `if wait.timed_out() && state.active.is_some()`，是正确写法。
- 建议：删掉 `|| wait.timed_out()`，只用 `*active > 0` 判定。
- 置信度：中
