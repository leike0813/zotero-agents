```

1199	            i += 1
```

- 分析：进入该分支时已经 `i += 1`，内层 `while` 先无条件 `append(lines[i])` 再判断是否以 `$$` 结尾，且从不检查首行是否自闭合。对 `$$E=mc^2$$`（MinerU 常见的单行 display math）这种输入，首行本身就以 `$$` 结束却被跳过判断，于是循环至少吞掉下一行；若文档后续没有以 `$$` 结尾的行，则吞到 EOF。被吞掉的行包括 `# Heading`、`|` 表格、`![...](...)`、`<table>`，因为这些结构只在主循环 `while i < len(lines)` 中被识别（1176-1288），内层循环不调用 `add_section`/`add_block` 分支。后果：标题不进 sections/navigation，表格/图片块丢失，被吞正文并入公式块（`translate=False`，见 1163 与 4736 的 `translate_required` 逻辑），翻译批次也不会要求翻译这段内容。对照同一文件里 `<table>` 分支（1214）显式做了 `if "</table>" not in raw.lower()` 的自闭合判断，说明此处是遗漏而非设计。
