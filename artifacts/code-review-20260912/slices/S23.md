### F1 [P2][正确性] rust/zotero-bridge/src/transport.rs:338 —— 无论是否做过校验都返回 `verified: true`，无 Content-Length / 无 sha 头时仍向 agent 宣称“已校验”
- 证据：
```

311	        .headers
312	        .get("x-zotero-bridge-sha256")
313	        .map(|value| normalize_sha256(value));
```

- 分析：长度校验（296-309）与校验和校验（315-330）都在 `if let Some(..)` 之内，二者都缺失时不做任何完整性检查，`verified` 仍硬编码为 true；commands.rs:2505/2404 把该字段原样写入成功 payload 的 `"verified"`。触发条件：Host/代理返回的下载响应没有 `Content-Length`（例如 `Transfer-Encoding: chunked` 或靠连接关闭定界）且没有 `X-Zotero-Bridge-Sha256`，此时“连接中途断开”的截断体（甚至带 chunk 框架的原始字节）会被当作 `verified: true` 写入磁盘，而 agent 会据此跳过复核。

- 置信度：高（`verified` 恒真为代码事实；可利用性取决于响应是否省略头）
