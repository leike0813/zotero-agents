### F3 [P3][并发] src/hooks.ts:1108 —— shutdown 步骤超时定时器未 `clearTimeout`，每次关闭遗留一个挂起定时器
- 证据：
```

    task,
    new Promise<{ ok: false; timedOut: true }>((resolve) => {
      setTimeout(() => {
```

- 分析：`task` 先完成时该 `setTimeout` 句柄没有任何引用被保留，无法清除，必须等到 `timeoutMs`（默认 3000ms）后才空跑一次 `resolve`（此时 `settled === true`，`resolve` 无效）。`onShutdown` 串行调用该方法约 15 次，即关闭期最多遗留 15 个挂起 3 秒的定时器；这在“定时器未清理”维度上是可证实的资源缺陷，影响有限（关闭路径，回调无副作用）。
- 建议：保留 `const timer = setTimeout(...)`，在 `Promise.race` 后 `finally { clearTimeout(timer); }`。
- 置信度：高（机制）/ 低（影响）
