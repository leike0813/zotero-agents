- 分析：`reconcile_restart` 把所有 `status = running` 的 public-maintenance 操作改写为 `failed / restart_reconciliation_failed`，receipt 为 `restart_external_effect_unknown` 且 `retryable:false`（runtime_public_maintenance_operation.rs:1089-1114）。该 handler 注册为 `client.reconcileSynthesisRuntimeWorkStateOnStartup`，但除名字外没有任何“仅启动期”守卫：一旦渲染层在会话中再次调用（页面重载、重复 mount、用户手动触发），正在执行的 WebDAV 同步/引用匹配/tag 审计会被判为失败；随后 worker 的 promotion checkpoint 读到 `is_terminal` 会返回 `operation_terminal`（同文件 840-842 行），把本可完成的工作整体中止，且用户无法 retry（retryable=false）。
