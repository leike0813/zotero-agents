# Collection Collector

## 目的

同じライブラリにすでに存在する関連文献で既存の Zotero コレクションを入力します。このワークフローは必須のフリーテキストコレクションスコープを解釈し、現在のメタデータ、タグ、Synthesis Topic メンバーシップを確認し、検証されたメンバーシップリストを適用します。

## 入力

| パラメータ | 必須 | 説明 |
| --- | --- | --- |
| `collection` | はい | パスで選択された既存の Zotero コレクション。 |
| `collectionScope` | はい | コレクションが表す意味、研究トピック、または文献境界。 |

Zotero アイテムの選択は不要です。

## 動作

1. ターゲットコレクションのライブラリ内のすべてのトップレベル通常アイテムをページングします。
2. ターゲットコレクションにすでに存在するアイテムを除外します。
3. メタデータ/タグの一致と関連する既存の Synthesis Topic から候補を構築します。
4. 最大 250 の候補を 20 件ずつバッチで意味的に評価します。
5. 関連度が `0.65` 以上の論文を選択し、各決定の証拠と理由を保持します。
6. 現在のメンバーシップを再確認し、残りのアイテムを workflow apply を通じて追加します。

このワークフローは自動であり、確認のために一時停止しません。ウェブ検索、新しい論文の取り込み、タグの編集、コレクションの作成、Synthesis Topic の変更は行いません。Topic コンテキストが不足している場合は、メタデータとタグの証拠に縮退します。

## 出力と適用

実行結果には、選択された Zotero アイテム参照、タイトル、関連度、証拠基盤、一致した Topic ID、理由、注意事項、選択診断が含まれます。空の選択は成功した no-op です。Apply はターゲットとアイテム参照を再度検証し、スキルの実行中にメンバーシップが変更された場合でも冪等性を維持します。
