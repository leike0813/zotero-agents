# Export Research Bundle

## 目的

宣言された論文意図に基づいて、既存の Zotero ライブラリと Synthesis コンテキストから読み取り専用のリサーチバンドルを Dashboard Products に自動構成します。バンドルは関連トピック、コア論文、および利用可能な分析アーティファクトを持つ関連論文を収集します。

## 入力

| パラメータ | 必須 | 説明 |
| --- | --- | --- |
| `paperTitle` | はい | 研究資料を見つけるために使用される作業原稿タイトル。 |
| `researchContent` | はい | 研究課題、方法、範囲、および意図された貢献。 |
| `articleType` | いいえ | 原稿タイプ（デフォルト：`original research`）。 |
| `maxTopics` | いいえ | 含める関連トピックの最大数、範囲 0–10（デフォルト：5）。 |
| `maxCorePapers` | いいえ | コア論文の最大数、範囲 1–50（デフォルト：20）。 |
| `maxRelatedPapers` | いいえ | Topic 以外から追加する論文の最大数、範囲 1–200（デフォルト：80）。選択した Topic から解決された論文はこの上限を超えても保持されます。 |

Zotero アイテムの選択は不要です。

## 動作

1. ユーザーから論文意図パラメータを受け取ります。
2. 既存の Synthesis Topics と限定された Zotero メタデータアンカーから候補資料を発見します。検索対象はタイトル、著者、年、出版物名、タグなどの索引済みメタデータであり、全文の意味検索ではありません。
3. コア論文と関連論文を区別するために有界評価を実行します。
4. トピックレポート、書誌メタデータ、および利用可能な v2 分析アーティファクト（ダイジェスト、参考文献、引用分析、会話内容）を持つリサーチバンドルを構成します。
5. コア論文の場合、ローカル画像付きの Markdown ソースを優先します。PDF にフォールバックします。どちらも利用できない場合は警告を記録します。
6. Dashboard Products に読み取り専用製品としてバンドルを登録します。

トピック、グラフ、分析アーティファクト、またはソースの可用性の欠如は優雅に縮退します — ワークフローはまだ読み取り可能な証拠で続行し、診断と警告を記録します。基準を満たす論文がない場合、実行は製品を登録せずに終了します。

## 出力と適用

リサーチバンドルは Dashboard Products に読み取り専用アーティファクトとして登録されます。その構造：

| パス | 説明 |
|------|-------------|
| `README.md` | 推奨読み順、ファイル命名、トピック/論文インデックスを持つエージェントおよび人間向けエントリーポイント |
| `manifest.json` | v2 アーティファクトパス、出所、ファイル整合性、診断の機械可読インベントリ |
| `topics/<topic-id>/report.md` | トピック統合レポート（利用可能な場合） |
| `papers/<paper-id>/metadata.json` | 論文ごとのポータブルな書誌メタデータ |
| `papers/<paper-id>/source.md` | Markdown ソース（利用可能な場合） |
| `papers/<paper-id>/digest-*.md` | Literature Analysis ダイジェストアーティファクト（利用可能な場合） |

ルートファイルと一緒に使用されるのは `topics/` と `papers/` セマンティックディレクトリのみです。Markdown 画像は、解決されたローカルパスが Markdown ファイルのディレクトリツリー内にある場合にのみ含まれます。ツリー外または欠落している画像は元のリンクを保持しますが、製品ファイルとして登録されません。

## 推定所要時間

ライブラリサイズ、候補数、トピック/グラフの可用性、およびバックエンドの応答速度によって異なります。進捗と結果は実行パネルに表示されます。

## モデル推奨

強力な意味的理解とツール呼び出し能力を持つモデルが推奨されます。このタスクでは、論文意図に対するトピックと論文の関連性を判断し、読み取り専用の Zotero および Synthesis コンテキストを正しく使用する必要があります。

## 依存関係

- **バックエンド**: Skill-Runner
- **スキル**: `export-research-bundle`
- **Host Bridge**: Zotero および Synthesis コンテキストの読み取り権限が必要
