# Literature Metadata Curator

## 目的

選択された Zotero 親アイテムの書誌メタデータクエリ、修正、補完を行います。このワークフローは、タイトル大文字表記の不一致、著者不足、不完全なジャーナル/巻/ページフィールド、不完全な DOI/ISBN エントリ、誤って設定されたアイテムタイプなどのケースを処理します。

## 入力

| パラメータ | 必須 | 説明 |
| --- | --- | --- |
| 識別子による高速検索をスキップ | いいえ（既定ではオフ） | Zotero の識別子検索を省略し、`literature-metadata-search` を直接実行します。 |

Zotero アイテムリストから正確に 1 つの親アイテムを選択してください。添付ファイルや複数アイテムは受け付けられません。

## 動作

ワークフローはユーザー確認なしで完全に自動実行されます。次の経路を使用します：

1. **ローカルファストパス（既定）**：アイテムに DOI、ISBN、または DOI、arXiv、PubMed 識別子に決定的に解決される URL がある場合、ワークフローは `runtime.hostApi.metadata.translateIdentifier`（制御された読み取り専用 Zotero `Translate.Search` ファサード）を呼び出します。候補識別子が一致し、貴重な書誌情報を含む場合、結果が直接書き戻されます。
2. **Agent 検索を強制**：**識別子による高速検索をスキップ**を有効にすると、ローカル検索を省略して `literature-metadata-search` を直接実行します。識別子は検索コンテキストとして保持されます。
3. **Skill-Runner フォールバック**：オプションが無効でも、ローカル検索が失敗するか信頼できない場合は、同じスキルを実行してウェブ上のメタデータを検索します。

すべての経路は同じ標準結果形式と apply ハンドラーを共有します。DOI、ISBN などの対応識別子があるにもかかわらず既定の実行で誤ったメタデータが得られる場合は、このオプションを有効にして Agent 検索を強制できます。候補照合と証拠の要件は変わりません。

両方のパスは同じ正規結果形式と同じ apply ハンドラを共有します。

### 書き戻しルール

ワークフローは親アイテムの書誌フィールドを更新します：

- タイトル、DOI、ISBN、ISSN、URL、要約、日付、言語、ライブラリカタログ
- ジャーナル/会議/書籍/学位論文/レポートフィールド（ジャーナル名、巻/号/ページ、出版社、会議名、学校、レポートタイプなど）
- 作成者（著者、機関著者など）
- 高信頼度の証拠でサポートされる場合の `itemType`（例：ジャーナル記事が学位論文に修正）

中国語で原著が発表された論文については、権威ある情報源で完全な著者一覧を確認できた場合にのみ、中国語表記の著者名を書き込みます。ピンイン、翻訳名、推測した漢字で著者を置き換えず、完全な一覧を確認できない場合は既存の著者を保持します。

ワークフローは添付ファイル、ノート、タグ、コレクション、関連アイテム、PDF ファイル、またはウェブスナップショットを**変更しません**。

安定した識別子がない場合、ワークフローは既存のタイトルを上書きするかアイテムタイプを変更するのは次の場合のみです：候補が同じ直接の作品であることが証明でき、少なくとも 2 つの独立した書誌シグナルが一致し、権威あるランディングページが裏付ける。コンテナタイトルは作品タイトルを置き換えるのではなく、適切なコンテナフィールドに書き込まれます。低信頼度、競合する候補、または疑わしいのみの結果はスキップされます。

## 出力と適用

メタデータの変更は選択された Zotero 親アイテムに直接適用されます。中間確認ステップは不要です。

## モデル推奨

- **ファストパスヒット**（対応識別子があり、オプションが無効）：バックエンドモデル不要。
- **オプション有効または `literature-metadata-search` へのフォールバック**：ウェブ検索機能を備えたモデルが推奨されます。タスクは軽量な取得と証拠検証です — 長文執筆能力は不要ですが、同音異義語、プレプリントと公開バージョン、論文と学位論文、異なる版を区別する必要があります。

## 依存関係

- **バックエンド**: Skill-Runner（ローカル検索ミス後のフォールバック用）
- **スキル**: `literature-metadata-search`
- **Zotero Host API**: `metadata.translateIdentifier`（制御された読み取り専用ファストパス）
- **Apply Handler**: `handlers.parent.updateMetadata`
