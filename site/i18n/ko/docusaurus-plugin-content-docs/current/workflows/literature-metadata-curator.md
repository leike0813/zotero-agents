# Literature Metadata Curator

## 목적

선택된 Zotero 상위 항목에 대한 서지 메타데이터를 쿼리, 수정 및 보완합니다. 이 워크플로는 제목 대소문자 불일치, 누락된 저자, 불완전한 저널/권/페이지 필드, 불완전한 DOI/ISBN 항목, 잘못 설정된 항목 유형 등의 사례를 처리합니다.

## 입력

| 파라미터 | 필수 | 설명 |
| --- | --- | --- |
| 식별자 빠른 경로 건너뛰기 | 아니요(기본값: 꺼짐) | Zotero 식별자 검색을 건너뛰고 `literature-metadata-search`를 바로 실행합니다. |

Zotero 항목 목록에서 정확히 하나의 상위 항목을 선택하십시오. 첨부파일 및 다중 항목은 허용되지 않습니다.

## 동작

이 워크플로는 사용자 확인 없이 완전히 자동으로 실행됩니다. 다음 경로를 사용합니다:

1. **로컬 패스트 패스(기본값)**: 항목에 DOI, ISBN 또는 DOI, arXiv 또는 PubMed 식별자로 결정적으로 해결되는 URL이 있는 경우, 워크플로는 `runtime.hostApi.metadata.translateIdentifier`(제어된 읽기 전용 Zotero `Translate.Search` 패사드)를 호출합니다. 후보 식별자가 일치하고 가치 있는 서지 정보를 포함하면 결과가 직접 기록됩니다.
2. **Agent 검색 강제**: **식별자 빠른 경로 건너뛰기**를 켜면 로컬 검색을 건너뛰고 `literature-metadata-search`를 바로 실행합니다. 식별자는 검색 컨텍스트로 유지됩니다.
3. **Skill-Runner 폴백**: 옵션이 꺼져 있어도 로컬 검색이 실패하거나 신뢰할 수 없으면 동일한 스킬로 웹 메타데이터를 검색합니다.

모든 경로는 동일한 표준 결과 형식과 apply 핸들러를 공유합니다. DOI, ISBN 등 지원되는 식별자가 있는데도 기본 실행이 잘못된 메타데이터를 반환하면 이 옵션을 켜 Agent 검색을 강제할 수 있습니다. 후보 일치 및 증거 요건은 완화되지 않습니다.

### 쓰기백 규칙

이 워크플로는 상위 항목의 서지 필드를 업데이트합니다:

- 제목, DOI, ISBN, ISSN, URL, 초록, 날짜, 언어, 라이브러리 카탈로그
- 저널/컨퍼런스/도서/학위논문/보고서 필드(저널명, 권/호/페이지, 출판사, 컨퍼런스명, 학교, 보고서 유형 등)
- 작성자(저자, 기관 저자 등)
- 높은 신뢰도의 증거로 지원되는 경우 `itemType`(예: 저널 기사가 학위논문으로 수정)

중국어로 처음 출판된 논문은 권위 있는 출처에서 전체 저자 목록을 확인한 경우에만 중국어 저자명을 기록합니다. 병음, 번역명 또는 추측한 한자로 저자를 대체하지 않으며, 전체 목록을 확인할 수 없으면 기존 저자를 유지합니다.

이 워크플로는 첨부파일, 노트, 태그, 컬렉션, 관련 항목, PDF 파일 또는 웹 스냅샷을 수정**하지 않습니다**.

안정적인 식별자 없이, 이 워크플로는 다음 경우에 기존 제목을 덮어쓰거나 항목 유형을 변경합니다: 후보가 동일한 직접 작품임을 증명할 수 있고, 적어도 두 개의 독립적인 서지 신호가 일치하며, 권위 있는 랜딩 페이지가 뒷받침할 때. 컨테이너 제목은 작품 제목을 대체하는 대신 적절한 컨테이너 필드에 기록됩니다. 낮은 신뢰도, 상충되는 후보 또는 의심만의 결과는 건너뜁니다.

## 출력 및 적용

메타데이터 변경은 선택된 Zotero 상위 항목에 직접 적용됩니다. 중간 확인 단계가 필요하지 않습니다.

## 모델 권장 사항

- **패스트 패스 적중**(지원되는 식별자가 있고 옵션이 꺼짐): 백엔드 모델 불필요.
- **옵션 활성화 또는 `literature-metadata-search`로 폴백**: 웹 검색 기능이 있는 모델이 권장됩니다. 이 작업은 경량 검색 및 증거 검증입니다 — 장문 작성 능력이 필요하지 않지만, 동음이의어, 사전 인쇄 vs. 출판 버전, 논문 vs. 학위논문 및 다른 판본을 구별해야 합니다.

## 종속성

- **백엔드**: Skill-Runner(로컬 검색 실패 후 폴백용)
- **스킬**: `literature-metadata-search`
- **Zotero Host API**: `metadata.translateIdentifier`(제어된 읽기 전용 패스트 패스)
- **Apply Handler**: `handlers.parent.updateMetadata`
