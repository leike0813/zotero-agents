# Literature Metadata Curator

## 목적

선택된 Zotero 상위 항목에 대한 서지 메타데이터를 쿼리, 수정 및 보완합니다. 이 워크플로는 제목 대소문자 불일치, 누락된 저자, 불완전한 저널/권/페이지 필드, 불완전한 DOI/ISBN 항목, 잘못 설정된 항목 유형 등의 사례를 처리합니다.

## 입력

| 파라미터 | 필수 | 설명 |
| --- | --- | --- |

사용자 구성 가능 파라미터가 없습니다. Zotero 항목 목록에서 정확히 하나의 상위 항목을 선택하십시오. 첨부파일 및 다중 항목은 허용되지 않습니다.

## 동작

이 워크플로는 사용자 확인 없이 완전히 자동으로 실행됩니다. 두 경로를 따릅니다:

1. **로컬 패스트 패스**: 항목에 DOI, ISBN 또는 DOI, arXiv 또는 PubMed 식별자로 결정적으로 해결되는 URL이 있는 경우, 워크플로는 `runtime.hostApi.metadata.translateIdentifier`(제어된 읽기 전용 Zotero `Translate.Search` 패사드)를 호출합니다. 후보 식별자가 일치하고 가치 있는 서지 정보를 포함하면 결과가 직접 기록됩니다.
2. **Skill-Runner 폴백**: 신뢰할 수 있는 식별자가 없거나, 로컬 검색이 결과를 반환하지 않거나, 변환기가 실패하거나, 후보가 신뢰할 수 없거나, 식별자가 일치하지 않으면, 워크플로는 경량 웹 기반 메타데이터 검색을 위해 `literature-metadata-search` 스킬을 실행합니다.

두 경로 모두 동일한 표준 결과 형식과 동일한 apply 핸들러를 공유합니다.

### 쓰기백 규칙

이 워크플로는 상위 항목의 서지 필드를 업데이트합니다:

- 제목, DOI, ISBN, ISSN, URL, 초록, 날짜, 언어, 라이브러리 카탈로그
- 저널/컨퍼런스/도서/학위논문/보고서 필드(저널명, 권/호/페이지, 출판사, 컨퍼런스명, 학교, 보고서 유형 등)
- 작성자(저자, 기관 저자 등)
- 높은 신뢰도의 증거로 지원되는 경우 `itemType`(예: 저널 기사가 학위논문으로 수정)

이 워크플로는 첨부파일, 노트, 태그, 컬렉션, 관련 항목, PDF 파일 또는 웹 스냅샷을 수정**하지 않습니다**.

안정적인 식별자 없이, 이 워크플로는 다음 경우에 기존 제목을 덮어쓰거나 항목 유형을 변경합니다: 후보가 동일한 직접 작품임을 증명할 수 있고, 적어도 두 개의 독립적인 서지 신호가 일치하며, 권위 있는 랜딩 페이지가 뒷받침할 때. 컨테이너 제목은 작품 제목을 대체하는 대신 적절한 컨테이너 필드에 기록됩니다. 낮은 신뢰도, 상충되는 후보 또는 의심만의 결과는 건너뜁니다.

## 출력 및 적용

메타데이터 변경은 선택된 Zotero 상위 항목에 직접 적용됩니다. 중간 확인 단계가 필요하지 않습니다.

## 모델 권장 사항

- **패스트 패스 적중**(DOI/ISBN/지원되는 URL 식별자 존재): 백엔드 모델 불필요.
- **`literature-metadata-search`로 폴백**: 웹 검색 기능이 있는 모델이 권장됩니다. 이 작업은 경량 검색 및 증거 검증입니다 — 장문 작성 능력이 필요하지 않지만, 동음이의어, 사전 인쇄 vs. 출판 버전, 논문 vs. 학위논문 및 다른 판본을 구별해야 합니다.

## 종속성

- **백엔드**: Skill-Runner(로컬 검색 실패 후 폴백용)
- **스킬**: `literature-metadata-search`
- **Zotero Host API**: `metadata.translateIdentifier`(제어된 읽기 전용 패스트 패스)
- **Apply Handler**: `handlers.parent.updateMetadata`
