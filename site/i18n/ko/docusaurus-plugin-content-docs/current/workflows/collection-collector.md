# Collection Collector

## 목적

동일한 라이브러리에 이미 존재하는 관련 문헌으로 기존 Zotero 컬렉션을 채웁니다. 이 워크플로는 필수 자유 텍스트 컬렉션 범위를 해석하고 현재 메타데이터, 태그 및 Synthesis Topic 멤버십을 검토하며 유효성이 검증된 멤버십 목록을 적용합니다.

## 입력

| 파라미터 | 필수 | 설명 |
| --- | --- | --- |
| `collection` | 예 | 경로로 선택된 기존 Zotero 컬렉션. |
| `collectionScope` | 예 | 컬렉션이 나타내는 의미, 연구 주제 또는 문헌 경계. |

Zotero 항목 선택은 필요하지 않습니다.

## 동작

1. 대상 컬렉션의 라이브러리에서 모든 최상위 일반 항목을 페이지 단위로 읽습니다.
2. 대상 컬렉션에 이미 있는 항목을 제외합니다.
3. 메타데이터/태그 일치 및 관련 기존 Synthesis Topic에서 후보를 구축합니다.
4. 최대 250개의 후보를 20개씩 배치로 의미적으로 평가합니다.
5. 관련성이 `0.65` 이상인 논문을 선택하고 각 결정에 대한 증거와 이유를 유지합니다.
6. 현재 멤버십을 다시 확인하고 나머지 항목을 workflow apply를 통해 추가합니다.

이 워크플로는 자동이며 확인을 위해 일시 중지하지 않습니다. 웹 검색, 새 논문 수집, 태그 편집, 컬렉션 생성 또는 Synthesis Topic 변경을 수행하지 않습니다. Topic 컨텍스트가 누락되면 메타데이터 및 태그 증거로 축소됩니다.

## 출력 및 적용

실행 결과에는 선택된 Zotero 항목 참조, 제목, 관련성 값, 증거 기반, 일치하는 Topic ID, 이유, 주의 사항 및 선택 진단이 포함됩니다. 빈 선택은 성공적인 no-op입니다. Apply는 대상 및 항목 참조를 다시 검증하며 스킬이 실행되는 동안 멤버십이 변경된 경우에도 멱등성을 유지합니다.
