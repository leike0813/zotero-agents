# Export/Import Literature Bundle

## 목적

메타데이터, 태그, 하위 노트, 첨부파일, 임베드 이미지 및 항목 간 관계를 포함하는 Zotero 상위 항목의 휴대 가능한 ZIP 번들을 내보내기 및 가져오기하여 Zotero 인스턴스 간 마이그레이션 또는 다른 연구자와의 협업을 용이하게 합니다.

## Export Literature Bundle

### 사용 사례

- 선택한 Zotero 항목을 독립 실행형 ZIP으로 백업
- 다른 Zotero 라이브러리를 사용하는 협력자와 문헌 공유
- 나중에 가져오기 위해 항목을 다른 Zotero 인스턴스로 전송

### 입력 제약

| 제약 유형 | 설명 |
|---------|------|
| 입력 단위 | 상위 항목 |
| 선택 | 하나 이상의 상위 항목. 첨부파일, 노트 및 하위 항목을 혼합할 수 없습니다 |
| 출력 | 사용자가 ZIP 저장 위치를 선택합니다. `.zip` 확장자가 누락된 경우 자동으로 추가됩니다 |

### 동작

1. 선택한 모든 항목이 상위 항목인지 검증합니다(첨부파일, 노트 또는 하위 항목은 허용되지 않음).
2. 각 상위 항목에 대한 서지 메타데이터, 태그, 임베드 이미지가 있는 하위 노트, 읽을 수 있는 로컬 첨부파일 및 링크 URL 첨부파일을 수집합니다.
3. Markdown 첨부파일의 경우 로컬 이미지 참조를 번들 상대 경로로 다시 작성하고 참조된 이미지를 포함합니다.
4. 같은 배치에서 내보낸 상위 항목 간의 항목 간 관계만 기록합니다.
5. 포맷 버전, 파일 인벤토리, 무결성 데이터 및 내보내기 경고가 포함된 `manifest.json`을 작성합니다.
6. 사용자가 선택한 위치의 ZIP 파일로 모든 것을 패키징합니다.

누락된 로컬 파일은 경고와 함께 건너뜁니다. Markdown의 원격 이미지는 그대로 유지됩니다(다운로드되지 않음). 저장 대화 상자를 취소하면 내보내기가 취소됩니다.

### 출력

| 아티팩트 | 설명 |
|----------|-------------|
| `manifest.json` | 포맷 버전, 파일 인벤토리, 무결성 정보, 내보내기 경고, 항목 간 관계 |
| 상위 항목 메타데이터 | 상위 항목별 휴대 가능한 서지 정보 및 태그 |
| 하위 노트 | 임베드 이미지가 있는 노트 |
| 첨부파일 | 읽을 수 있는 로컬 첨부파일. 동반 로컬 이미지가 있는 Markdown 첨부파일 |
| 링크 URL 첨부파일 | 링크 정보 |

## Import Literature Bundle

### 사용 사례

- 이전에 내보낸 문헌 번들을 현재 Zotero 라이브러리로 복원
- 협력자가 공유한 문헌 가져오기

### 입력 제약

| 제약 유형 | 설명 |
|---------|------|
| 입력 단위 | 워크플로(Zotero 항목 선택 불필요) |
| 가져오기 방법 | Export Literature Bundle에서 생성한 ZIP 파일 선택 |
| 컬렉션 컨텍스트 | 현재 보기에서 실제 컬렉션이 선택된 경우 새 항목이 해당 컬렉션에 추가됩니다. 그렇지 않으면 항목이 라이브러리 루트로 가져오기됩니다 |

### 동작

1. 번들을 검증합니다: 유형, 버전, 아카이브 경로, 파일 인벤토리, 크기 및 무결성. 검증 실패는 라이브러리를 수정하지 않고 중단합니다.
2. 번들의 각 상위 항목에 대해 새 Zotero 항목 그래프를 생성합니다: 서지 메타데이터, 태그, 첨부파일, 노트, 임베드 이미지 및 링크 URL 첨부파일.
3. 같은 번들에서 성공적으로 가져온 상위 항목 간의 항목 간 관계를 복원합니다.
4. 단일 상위 항목 가져오기가 실패하면 해당 항목과 새로 생성된 하위 항목을 정리한 다음 나머지 항목으로 계속합니다.

가져오기는 원래 Zotero 항목 ID 또는 키를 재사용하지 않으며, 기존 항목을 중복 제거, 병합 또는 덮어쓰지 않습니다. 같은 번들을 다시 가져오면 독립적인 사본이 생성됩니다.

### 출력

전체 항목 그래프가 있는 새 Zotero 상위 항목. 누락된 파일, 정리 실패 또는 관계 복원 실패는 경고로 보고됩니다. 결과가 부분적으로 완료되었을 수 있습니다.

## 예상 소요 시간

항목 수, 첨부파일 크기 및 로컬 디스크 속도에 따라 다릅니다. 순수 메타데이터 또는 작은 노트는 빠르게 완료됩니다. 큰 PDF나 많은 이미지는 비례하여 시간을 증가시킵니다.

## 종속성

- 백엔드 연결 불필요
- Zotero 로컬 스토리지 및 파일 액세스 권한에만 의존
