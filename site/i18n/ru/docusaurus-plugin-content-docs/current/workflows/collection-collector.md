# Collection Collector

## Назначение

Заполнить существующую коллекцию Zotero релевантной литературой, уже присутствующей в той же библиотеке. Workflow интерпретирует требуемую область коллекции в виде свободного текста, просматривает текущие метаданные, теги и членство в Synthesis Topic и применяет проверенный список членства.

## Ввод

| Параметр | Обязательно | Описание |
| --- | --- | --- |
| `collection` | Да | Существующая коллекция Zotero, выбранная по пути. |
| `collectionScope` | Да | Значение, тема исследования или граница литературы, представленная коллекцией. |

Выбор элементов Zotero не требуется.

## Поведение

1. Постранично просмотреть все регулярные элементы верхнего уровня в библиотеке целевой коллекции.
2. Исключить элементы, уже присутствующие в целевой коллекции.
3. Построить кандидатов из совпадений метаданных/тегов и релевантных существующих Synthesis Topics.
4. Семантически оценить не более 250 кандидатов партиями по 20.
5. Выбрать статьи с релевантностью не менее `0.65` и сохранить доказательства и обоснование для каждого решения.
6. Перепроверить текущее членство и добавить оставшиеся элементы через workflow apply.

Workflow автоматичен и не приостанавливается для подтверждения. Он не выполняет поиск в вебе, не импортирует новые статьи, не редактирует теги, не создает коллекции и не изменяет Synthesis Topics. Отсутствие контекста Topic деградирует до доказательств метаданных и тегов.

## Вывод и применение

Результат выполнения содержит выбранные ссылки на элементы Zotero, заголовки, значения релевантности, базу доказательств, совпавшие ID Topic, причины, оговорки и диагностики выбора. Пустой выбор — это успешная no-op операция. Apply повторно проверяет цель и ссылки на элементы и остается идемпотентным, если членство изменилось во время выполнения навыка.
