# Tag Auditor

## Назначение

Сканирование всех регулярных элементов верхнего уровня в библиотеке Zotero по контролируемому словарю тегов и отчет о соответствии тегов для каждого элемента. Результаты записываются на панель аудита тегов Synthesis Workbench для проверки и последующей регуляции.

## Ввод

Параметры и выбор элементов Zotero не требуются. Workflow работает со всей библиотекой.

## Поведение

1. Загрузить контролируемый словарь тегов из Synthesis через `exportTagVocabularyForRegulator`.
2. Постранично просмотреть все регулярные элементы верхнего уровня в библиотеке (исключая дочерние элементы, заметки, вложения и удаленные элементы).
3. Для каждого элемента собрать его текущие теги и оценить соответствие: тег не соответствует, если он отсутствует в контролируемом словаре.
4. Сгруппировать записи аудита по ID библиотеки и записать их в Synthesis через `replaceTagAuditRecords`.

Workflow полностью автоматичен и не изменяет никакие элементы или теги Zotero. Это сканирование только для чтения, которое создает записи аудита для панели Тегов.

## Вывод и применение

Панель аудита Тегов Synthesis Workbench отображает записи аудита для каждого элемента, каждая из которых содержит:

| Поле | Описание |
|-------|-------------|
| `itemKey` | Ключ элемента Zotero |
| `compliant` | Все ли теги элемента находятся в контролируемом словаре |
| `nonCompliantTags` | Список тегов, не найденных в контролируемом словаре |

Результат выполнения суммирует количество проверенных элементов и элементов, требующих регуляции тегов, для каждой библиотеки. Повторный запуск workflow заменяет предыдущие записи аудита (идемпотентно в рамках одного состояния словаря).

Обязательным условием является то, что контролируемый словарь тегов должен быть уже определен на странице Тегов Synthesis Workbench.

## Зависимости

- Подключение к бэкенду не требуется
- **Контролируемый словарь**: Сначала должен быть определен контролируемый словарь тегов; см. [Управление тегами](../synthesis/tags)
