# Literature Metadata Curator

## Назначение

Запрос, исправление и дополнение библиографических метаданных для выбранного родительского элемента Zotero. Workflow обрабатывает такие случаи, как несогласованность регистра заголовка, отсутствующие авторы, неполные поля журнала/тома/страницы, неполные записи DOI/ISBN и неправильно установленные типы элементов.

## Ввод

| Параметр | Обязательно | Описание |
| --- | --- | --- |
| Пропустить быстрый поиск по идентификатору | Нет (по умолчанию выключено) | Пропустить поиск по идентификатору Zotero и сразу запустить `literature-metadata-search`. |

Выберите ровно один родительский элемент в списке элементов Zotero. Вложения и множественные элементы не принимаются.

## Поведение

Workflow выполняется полностью автоматически без подтверждения пользователя. Он использует следующие пути:

1. **Локальный быстрый путь (по умолчанию)**: Если элемент имеет DOI, ISBN или URL, который детерминированно разрешается в идентификатор DOI, arXiv или PubMed, workflow вызывает `runtime.hostApi.metadata.translateIdentifier` (контролируемый доступ только для чтения Zotero `Translate.Search` фасад). Когда идентификатор-кандидат совпадает и содержит ценную библиографическую информацию, результаты записываются напрямую.
2. **Принудительный поиск Agent**: При включении **Пропустить быстрый поиск по идентификатору** локальный поиск не выполняется, а `literature-metadata-search` запускается сразу. Идентификатор сохраняется как контекст поиска.
3. **Резервный вариант Skill-Runner**: Если опция выключена, но локальный поиск завершается без результата, ошибкой или ненадёжным кандидатом, для веб-поиска запускается тот же навык.

Все пути используют один канонический формат результата и обработчик применения. Если у элемента уже есть DOI, ISBN или другой поддерживаемый идентификатор, но обычный запуск возвращает неверные метаданные, включите опцию для принудительного поиска Agent. Требования к совпадению и доказательствам не меняются.

### Правила записи

Workflow обновляет библиографические поля родительского элемента:

- Заголовок, DOI, ISBN, ISSN, URL, аннотация, дата, язык, библиотечный каталог
- Поля журнала/конференции/книги/диссертации/отчета (название журнала, том/выпуск/страницы, издатель, название конференции, школа, тип отчета и т.д.)
- Создатели (авторы, институциональные авторы и т.д.)
- `itemType`, когда поддерживается доказательствами высокой достоверности (например, статья журнала исправлена на диссертацию)

Для работы, изначально опубликованной на китайском языке, Agent записывает имена авторов китайскими иероглифами только тогда, когда авторитетный источник подтверждает полный список. Пиньинь, переводы или угаданные иероглифы не заменяют авторов; без подтверждённого полного списка сохраняются существующие авторы.

Workflow **не** изменяет вложения, заметки, теги, коллекции, связанные элементы, PDF-файлы или веб-снимки.

Без стабильного идентификатора workflow перезаписывает существующий заголовок или изменяет тип элемента только когда: кандидат может быть доказан как то же самое прямое произведение, по крайней мере два независимых библиографических сигнала совпадают, и авторитетная целевая страница подтверждает это. Заголовки контейнеров записываются в соответствующее поле контейнера, а не заменяют заголовок произведения. Результаты с низкой достоверностью, противоречивые кандидаты или только предположительные результаты пропускаются.

## Вывод и применение

Изменения метаданных применяются непосредственно к выбранному родительскому элементу Zotero. Промежуточный шаг подтверждения не требуется.

## Рекомендация модели

- **Попадание в быстрый путь** (поддерживаемый идентификатор присутствует и опция выключена): Модель бэкенда не нужна.
- **Опция включена или резервный вариант `literature-metadata-search`**: Рекомендуется модель с возможностью веб-поиска. Задача — легкое извлечение и проверка доказательств — не требует способности к длинному письму, но должна различать омонимы, версии препринта и публикации, статьи и диссертации, различные издания.

## Зависимости

- **Бэкенд**: Skill-Runner (для резервного варианта после неудачного локального поиска)
- **Навык**: `literature-metadata-search`
- **Zotero Host API**: `metadata.translateIdentifier` (контролируемый доступ только для чтения)
- **Apply Handler**: `handlers.parent.updateMetadata`
